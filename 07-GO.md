## Go Fundamentals

### What is Go?

**Go** (also called **Golang**) is an open-source programming language developed by Google in 2009. It was designed by Rob Pike, Ken Thompson, and Robert Griesemer.

**Key Design Goals:**
- **Simplicity**: Minimalistic design, avoiding excessive abstractions
- **Efficiency**: Fast compilation and execution
- **Safety**: Statically typed with compile-time checks
- **Concurrency**: Built-in support for concurrent programming
- **System Programming**: Suitable for system-level programming

**Key Features:**
- Statically typed
- Garbage collected
- Built-in concurrency (goroutines, channels)
- Fast compilation
- Rich standard library
- Cross-platform support

## Go Workspace and Modules

### Workspace Architecture

Go uses a workspace structure:
- **src/**: Source code directory
- **pkg/**: Compiled package files
- **bin/**: Executable binaries

### Go Modules

Modern Go uses modules for dependency management:
- **go.mod**: Module definition file
- **go.sum**: Dependency checksums
- Version management
- Dependency resolution

## Data Types and Variables

### Basic Types

- **Numeric**: int, int8, int16, int32, int64, uint, uint8, uint16, uint32, uint64, float32, float64, complex64, complex128
- **Boolean**: bool
- **String**: string
- **Byte**: byte (alias for uint8)
- **Rune**: rune (alias for int32, represents Unicode code point)

### Variable Declaration

```go
var x int = 10
var y = 20  // Type inference
z := 30     // Short declaration
```

### Zero Values

All variables have zero values:
- Numeric types: 0
- Boolean: false
- String: ""
- Pointers, slices, maps, channels, interfaces: nil

## Functions and Methods

### Functions

```go
func functionName(param1 type1, param2 type2) returnType {
    // code
    return value
}

// Multiple return values
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

// Named return values
func calculate(x, y int) (sum int, product int) {
    sum = x + y
    product = x * y
    return  // Naked return
}
```

### Methods

```go
type Rectangle struct {
    Width  float64
    Height float64
}

func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

// Pointer receiver
func (r *Rectangle) Scale(factor float64) {
    r.Width *= factor
    r.Height *= factor
}
```

## Pointers and Memory

### Pointers

```go
var x int = 10
var p *int = &x  // p is a pointer to x
*p = 20          // Dereference and modify
```

### Pointer Receivers

Use pointer receivers when:
- Method needs to modify the receiver
- Struct is large (avoid copying)
- Consistency with other methods

## Data Structures

### Arrays

```go
var arr [5]int           // Array of 5 integers
arr := [5]int{1, 2, 3, 4, 5}
arr := [...]int{1, 2, 3} // Compiler determines size
```

### Slices

```go
var slice []int                    // Nil slice
slice := []int{1, 2, 3}           // Slice literal
slice := make([]int, 5)           // Slice with length 5
slice := make([]int, 5, 10)       // Slice with length 5, capacity 10

// Slice operations
slice = append(slice, 4)          // Append
subSlice := slice[1:3]            // Slice slicing
```

**Key Differences:**
- Arrays: Fixed size, value type
- Slices: Dynamic size, reference type

### Maps

```go
var m map[string]int              // Nil map
m := make(map[string]int)         // Empty map
m := map[string]int{"a": 1, "b": 2} // Map literal

// Map operations
m["key"] = value                  // Insert/update
value := m["key"]                 // Get value
value, ok := m["key"]             // Get with existence check
delete(m, "key")                  // Delete
```

### Structs

```go
type Person struct {
    Name string
    Age  int
}

p := Person{Name: "Alice", Age: 30}
p.Name = "Bob"
```

## Concurrency

### Goroutines

```go
go function()  // Launch goroutine
```

**Characteristics:**
- Lightweight threads
- Managed by Go runtime
- Efficient context switching
- Share memory space

### Channels

```go
ch := make(chan int)        // Unbuffered channel
ch := make(chan int, 10)    // Buffered channel

ch <- value    // Send
value := <-ch  // Receive
close(ch)      // Close channel
```

**Channel Types:**
- **Unbuffered**: Synchronous, sender blocks until receiver ready
- **Buffered**: Asynchronous, sender blocks only when buffer full

### Select Statement

```go
select {
case msg := <-ch1:
    // Handle message from ch1
case msg := <-ch2:
    // Handle message from ch2
case ch3 <- value:
    // Send to ch3
default:
    // Non-blocking default case
}
```

### Concurrency Patterns

- **Worker Pools**: Fixed number of goroutines processing work
- **Fan-out/Fan-in**: Distribute work and collect results
- **Pipeline**: Chain of stages processing data
- **Context**: Cancellation and timeout

## Error Handling

### Error Interface

```go
type error interface {
    Error() string
}
```

### Error Handling Patterns

```go
// Explicit error return
result, err := function()
if err != nil {
    // Handle error
    return err
}

// Error wrapping
if err != nil {
    return fmt.Errorf("context: %w", err)
}

// Custom error types
type MyError struct {
    Code    int
    Message string
}

func (e *MyError) Error() string {
    return fmt.Sprintf("Error %d: %s", e.Code, e.Message)
}
```

### Defer, Panic, Recover

```go
// Defer: Execute function when surrounding function returns
defer cleanup()

// Panic: Stop normal execution
panic("something went wrong")

// Recover: Catch panic
defer func() {
    if r := recover(); r != nil {
        // Handle panic
    }
}()
```

## Testing

### Unit Tests

```go
func TestFunction(t *testing.T) {
    result := function()
    if result != expected {
        t.Errorf("Expected %v, got %v", expected, result)
    }
}
```

### Table-Driven Tests

```go
func TestFunction(t *testing.T) {
    tests := []struct {
        input    int
        expected int
    }{
        {1, 2},
        {2, 4},
        {3, 6},
    }
    
    for _, tt := range tests {
        result := function(tt.input)
        if result != tt.expected {
            t.Errorf("function(%d) = %d, expected %d", tt.input, result, tt.expected)
        }
    }
}
```

### Benchmarks

```go
func BenchmarkFunction(b *testing.B) {
    for i := 0; i < b.N; i++ {
        function()
    }
}
```


### Generics (Go 1.18+)

```go
func Map[T, U any](slice []T, fn func(T) U) []U {
    result := make([]U, len(slice))
    for i, v := range slice {
        result[i] = fn(v)
    }
    return result
}
```

## Best Practices

1. **Error Handling**: Always check and handle errors explicitly
2. **Concurrency**: Use channels for communication, avoid shared memory
3. **Interfaces**: Keep interfaces small and focused
4. **Naming**: Use clear, descriptive names following Go conventions
5. **Documentation**: Write godoc comments for exported functions
6. **Testing**: Write tests alongside code
7. **Defer**: Use defer for cleanup operations
8. **Pointers**: Use pointers when modifying or for large structs
