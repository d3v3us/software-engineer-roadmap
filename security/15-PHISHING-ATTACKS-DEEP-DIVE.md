## What is Phishing?

### Definition

**Phishing**: Social engineering attack that attempts to trick users into revealing sensitive information.

**Key Characteristics:**
- **Social engineering**: Social engineering
- **Deception**: Deceptive tactics
- **Sensitive information**: Credentials, data
- **Email/web**: Email or web-based

### Real-World Analogy

**Phishing = Fishing:**
- **Bait**: Phishing bait
- **Hook**: Phishing hook
- **Catch**: Victim catch
- **Fishing**: Phishing attack

**Attack:**
- **Phisher**: Attacker
- **Bait**: Deceptive message
- **Victim**: Target user
- **Information**: Stolen information

## Phishing Techniques

### Technique 1: Email Spoofing

**Email Spoofing:**
- **Fake sender**: Fake sender address
- **Display name**: Spoofed display name
- **Domain**: Similar domain
- **Legitimate**: Looks legitimate

**Example:**
```
From: support@paypa1.com (not paypal.com)
Subject: Account Suspension
```

### Technique 2: URL Manipulation

**URL Manipulation:**
- **Similar domains**: Similar domain names
- **Typosquatting**: Typosquatting
- **Subdomains**: Malicious subdomains
- **Short URLs**: Shortened URLs

**Examples:**
- **paypa1.com**: Instead of paypal.com
- **g00gle.com**: Instead of google.com
- **amaz0n.com**: Instead of amazon.com

### Technique 3: Social Engineering

**Social Engineering:**
- **Urgency**: Create urgency
- **Authority**: Fake authority
- **Fear**: Create fear
- **Greed**: Appeal to greed

**Tactics:**
- **Urgent action**: "Act now!"
- **Account suspension**: "Account will be suspended"
- **Prize**: "You've won!"
- **Threat**: "Legal action"

### Technique 4: Malicious Attachments

**Malicious Attachments:**
- **Documents**: Malicious documents
- **Macros**: Macro-enabled files
- **Executables**: Executable files
- **ZIP files**: Compressed files

**Examples:**
- **PDF**: Malicious PDF
- **Word**: Macro-enabled Word
- **Excel**: Macro-enabled Excel
- **ZIP**: Compressed malware
