## What is Agile?

### Definition

**Agile**: Iterative approach to software development that emphasizes flexibility and collaboration.

**Key Concepts:**
- **Iterative**: Iterative development
- **Flexible**: Flexible to changes
- **Collaborative**: Team collaboration
- **Customer-focused**: Customer-focused

### Real-World Analogy

**Agile = Building House Incrementally:**
- **Foundation**: Basic structure
- **Add rooms**: Add rooms incrementally
- **Adjust**: Adjust based on needs
- **Iterative**: Iterative building

**Waterfall = Complete Blueprint:**
- **Complete plan**: Complete plan first
- **Build all**: Build everything
- **Rigid**: Rigid plan
- **Hard to change**: Hard to change

## Agile vs Waterfall

### Comparison

| Aspect | Waterfall | Agile |
|--------|-----------|-------|
| **Approach** | Sequential | Iterative |
| **Flexibility** | Low | High |
| **Feedback** | Late | Early |
| **Risk** | High | Low |
| **Change** | Hard | Easy |

### When to Use

**Use Waterfall When:**
- **Fixed requirements**: Fixed requirements
- **Predictable**: Predictable project
- **Regulated**: Regulated industry

**Use Agile When:**
- **Changing requirements**: Changing requirements
- **Uncertain**: Uncertain project
- **Innovation**: Innovation needed
